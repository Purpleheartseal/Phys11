# آزمایشگاه تعاملی فیزیک یازدهم (رشته علوم تجربی — ویژه کنکور)

این برنامه بر اساس کتاب درسی **فیزیک (۲) پایه یازدهم رشته علوم تجربی (`C111244.pdf`)** طراحی شده است و تمام **۳ فصل و ۲۸ زیربخش** کتاب را به صورت کاملاً مجزا، بصری و تعاملی پوشش می‌دهد.

## اجرای برنامه

در ترمینال داخل پوشه `phys11-lab` دستور زیر را اجرا کنید:

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:5173` را در مرورگر باز کنید.

## ساختار آموزشی هر زیربخش

1. **آزمایشگاه تعاملی و فرمول زنده**: بازی با متغیرها، مشاهده فوری بردارها، نمودارها، مدارها و جایگذاری عددی زنده در فرمول.
2. **درسنامه فشرده و نکات کنکوری**: خلاصه دقیق مطابق صفحات کتاب درسی، جدول متغیرها و یکاها، نکات طلایی کنکور و تله‌های رایج طراحان.
3. **بانک تمرین، تست کنکوری و مولّد تمرین نامحدود**: تست‌های ۴ گزینه‌ای و مسائل عددی با راهنمایی و پاسخ تشریحی مرحله‌به‌مرحله + تولید تمرین تصادفی نامحدود.
